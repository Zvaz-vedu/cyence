# Editing the CYENCE website

The website has a content manager at **https://cyence.eu/admin/** (address
to be confirmed with the domain). Everything you change there is saved to the
website's repository on GitHub, and the site rebuilds automatically – your
change is live about a minute later.

## Signing in

1. You need a free **GitHub account**. Send your username to the web team;
   they add you to the repository.
2. Open `/admin/` and click **Sign In with GitHub**.

## What is where

| In the menu | What you edit |
|---|---|
| **Pages** | Every page of the site: homepage, About pages, Apply, Programme, Public Day overview, Media, Partners, Contact, Privacy. |
| **News** | News, events and press releases. They appear on the homepage and on the News page; press releases also on Media. |
| **Projects** | One entry per participant project (in English). |
| **Public Day cities** | The page of each of the six cities. |
| **Lists & data** | Team members, partners and their logos, Public Day venues and audience sizes. |

## English and Czech

Pages, news and Public Day cities exist in both languages. The editor shows
them **side by side**: English on the left, Czech on the right. Fill in both.
Projects are in English only – they appear on both language versions of the
site automatically.

## Pages are built from blocks

Each page is a list of **blocks** (a slogan, a text with a heading, a row of
numbers, a call to action, …). You can edit a block, change the order by
dragging, add a new one or remove one. Some useful conventions:

- **Links**: write a page path such as `/apply` or `/about/event` – it
  works in both languages. External links start with `https://`.
- **Slogans**: wrap the words to underline in asterisks:
  `Science has *no borders.*`
- **Numbers (bento)**: the first number gets the big yellow tile, the second
  the black tile, the third the blue one, the fourth the outlined one.

## News: article or link?

A news item **with text** gets its own page. A news item **without text but
with a link** is a short card that sends people straight to the link – for
example a registration form or an external article.

## Images

Upload photos where a field says *Photo* or *Logo*. Keep photos under about
2 MB (2000 px wide is plenty). Team photos should be square.

## Testing locally (for the web team)

In Chrome, Edge or Brave, run the site locally (`npm run dev`), open
`http://localhost:1313/admin/`, click **Work with Local Repository** and
select the project folder. Changes are written straight to your files – commit
them with Git as usual.

## Changing the editor itself

The menu, fields and block types are generated by
`tools/build-cms-config.py`. After adding a block type, country, research
field or Public Day city, run it again (`pip install pyyaml` once).
